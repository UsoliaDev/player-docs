# 概览

*美食与冒险的旅途*

---

?> 目前处于试运行状态，现有内容和机制不代表最终呈现

Cozzy Journey 是一个以「美食与冒险」为主题的 mod 服务器，加入了大量食物拓展，以及扩充原版玩法与机制的模组。

## 开始

### 客户端下载

想要游玩 Cozzy Journey，你需要下载专用的游戏客户端。

[通过 Github 下载 ↗](https://github.com/UsoliaDev/Journey-Client/releases/latest)

如果无法打开 Github，可以在 QQ 群内下载最新版本的压缩包。

### 开始游戏之前

请阅读与该服务器有关的规则：

- [生存玩法服务器规则 ↗](https://policies.usolia.net/#/docs/server/rules?id=%e7%94%9f%e5%ad%98%e7%8e%a9%e6%b3%95%e6%9c%8d%e5%8a%a1%e5%99%a8%e8%a7%84%e5%88%99)
- [Cozzy Journey 服务器规则 ↗](https://policies.usolia.net/#/docs/server/rules?id=cozzy-journey-%e6%9c%8d%e5%8a%a1%e5%99%a8%e8%a7%84%e5%88%99)
